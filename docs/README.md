# **Документация**
---
## *1. Общее описание решения*
---
Библиотека Python-фунций для вычисления характеристик геометрических фигур (круг, квадрат).
Проект включает 4 модуля:
- 'square.py' -- функции для квадрата
- 'circle.py' -- функции для круга
- 'triangle.py' -- функции для треугольника
- 'rectangle.py' -- функции для прямоугольника

Формулы, используемые в библиотеке:

| Функция  | Круг (circle.py) | Квадрат (square.py) | Треугольник (triangle.py) | Прямоугольник (rectangle.py) | 
| -------- | ---------------- | ------------------- | ------------------------- | ---------------------------- |
| Периметр | 2πR              | 4a                  | a + b + c                 | 2 * (a + b)                  |
| Площадь  | πR²              | a²                  | a * h / 2                 | a * b                        |

## *2. Описание функций*
---

### square.py

#### area()

Получает:

a (неотрицательное число): сторона квадрата

Возвращает:

int / float (неотрицательное число): площадь квадрата

Формула:
a²

Возвращает площадь квадрата с заданной стороной

*Пример вызова:*
'''
python3
>>> from square import area
>>> area(10)
100
'''

#### perimeter()

Получает:

a (неотрицательное число): сторона квадрата

Возвращает:

int / float (неотрицательное число): периметр квадрата

Формула:
4a

Возвращает периметр квадрата с заданной стороной

*Пример вызова:*
'''
python3
>>> from square import perimeter
>>> perimeter(5)
20
'''

### circle.py

#### area()

Получает:

R (неотрицательное число): радиус круга

Возвращает:

float (неотрицательное число с плавающей точкой): площадь круга

Формула:
πR²

Возвращает площадь круга заданного радиуса

*Пример вызова:*
'''
python3
>>> from circle import area
>>> area(4)
50.26548245743669
'''

#### perimeter()

Получает:

R (неотрицательное число): радиус круга

Возвращает:

float (неотрицательное число с плавающей точкой): периметр круга

Формула:
2πR

Возвращает периметр круга заданного радиуса

*Пример вызова:*
'''
python3
>>> from circle import perimeter
>>> perimeter(7)
43.982297150257104
'''

### triangle.py

#### area()

Получает:

a (неотрицательное число): сторона треугольника
h (неотрицательное число): высота, опущенная на эту сторону

Возвращает:

float (неотрицательное число с плавающей точкой): площадь треугольника

Формула:
a * h / 2

Возвращает площадь треугольника по стороне и высоте, опущенной на эту сторону

*Пример вызова:*
'''
python3
>>> from triangle import area
>>> area(1, 2)
1.0
'''

#### perimeter()

Получает:

a (неотрицательное число): первая сторона треугольника
b (неотрицательное число): вторая сторона треугольника
c (неотрицательное число): третья сторона

Возвращает:

int / float (неотрицательное число): периметр треугольника

Формула:
a + b + c

Возвращает периметр треугольника с заданными сторонами

*Пример вызова:*
'''
python3
>>> from triangle import perimeter
>>> perimeter(1, 1, 1)
3
'''

### rectangle.py

#### area()

Получает:

a (неотрицательное число): первая сторона прямоугольника
b (неотрицательное число): вторая сторона прямоугольника

Возвращает:

int / float (неотрицательное число): площадь прямоугольника

Формула:
a * b

Возвращает площадь прямоугольника со сторонами a и b

*Пример вызова:*
'''
python3
>>> from rectangle import area
>>> area(3, 4)
12
'''

#### perimeter()

Получает:

a (неотрицательное число): первая сторона прямоугольника
b (неотрицательное число): вторая сторона прямоугольника

Возвращает:

int / float (неотрицательное число): периметр прямоугольника

Формула:
2 * (a + b)

Возвращает периметр прямоугольника по длинам двух смежных сторон a и b

*Пример вызова:*
'''
python3
>>> from rectangle import perimeter
>>> perimeter(3, 4)
14
'''


> [!IMPORTANT]
> Аргумент функций должен быть числом неотрицательным.

## Как запустить

Скачать его можно с официального сайта: https://www.python.org/downloads/

После установки проверьте, что Python работает:
'''
bash
python3 --version
'''
