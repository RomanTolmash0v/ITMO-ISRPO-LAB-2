## **Лабораторная работа №2 "Документирование" по дисциплине "Инструментальные средства разработки програмного обеспечения"**

## **Описание**
Библиотека функций на Python, предназначенная для вычисления характеристик геометрических фигур

## **Структура**
- 'square.py' -- функции для квадрата
- 'circle.py' -- функции для круга
- 'triangle.py' -- функции для треугольника
- 'rectangle.py' -- функции для прямоугольника
- 'docs/README.md' -- документация
